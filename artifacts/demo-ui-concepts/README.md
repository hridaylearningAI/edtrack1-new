# EdTrack ONE demo workspace concepts

Seven static, AI-generated visual directions for the logged-in institution overview. Created with the built-in image_gen tool, informed by the Lintel reference and the current EdTrack product, demo fixtures, and chat context. These are concept images, not implemented interfaces. The homepage was not changed.

All figures, names and schedules in the concepts are illustrative demo content. Generated charts and comparison figures vary across images; implementation should bind all screens to one consistent fixture dataset and verify units, periods and chart semantics. The stage counts represent different cohorts/periods and should not be treated as a single conversion funnel without normalization. Generated wordmarks and icon treatments are exploratory; implementation should use approved brand assets.

## 01 · Neumorphism

[Full image](01-neumorphism.png) — Soft tactile depth.

Intended motion: Controls depress over 120ms; selected tabs settle into an inset state; panels reveal with a short fade.

## 02 · Glassmorphism

[Full image](02-glassmorphism.png) — Luminous frosted layers.

Intended motion: Navigation highlight glides over 180ms; drawers fade and move 8px; background stays still.

## 03 · Modern Retro

[Full image](03-modern-retro.png) — Warm ivory, rust and olive.

## 04 · Brutalist

[Full image](04-brutalist.png) — Confident ink and acid yellow.

## 05 · Bauhaus

[Full image](05-bauhaus.png) — Geometric primary accents.

## 06 · Editorial

[Full image](06-editorial.png) — Serif hierarchy and forest green.

## 07 · Hybrid

[Full image](07-hybrid.png) — Editorial foundation with tactile accents.

Intended motion: Navigation glides over 180ms; controls depress over 120ms; journey connectors draw over 400ms; drawers ease in over 220ms.

## Shared interaction direction

Navigation opens real modules; metrics drill into filtered records; attention rows open review queues; Enrol student starts a sample enrolment; schedule rows open event detail. Use a coherent enquiry → enrolment → learning → assessment → fees → completion story for the investor walkthrough. These behaviors are proposed, not implemented by these artifacts.

Honor reduced-motion preferences by removing chart tracing and spatial movement. Keep keyboard focus visible and all data readable without motion. Animate state changes rather than adding continuous decorative effects.

Recommended shortlist: 06 Editorial for restraint, 07 Hybrid for more personality, 02 Glassmorphism for closest affinity to the reference. Exact generation prompts are saved in prompts.json.
